# 時間割自動編成Webアプリ 要件定義

対象: 日本の小学校・中学校・高等学校の週時間割編成

- 自動提案は整数計画法（PuLP + CBC）で行う
- 人が画面上で微調整し、固定した部分を保ったまま再提案できる
- 強化学習アプローチ（`archive/` 予定の `env/`, `keras*.py`, `chainer0001.py`）は採用しない

---

### 1.2 週コマ数（年間時数 ÷ 授業週数）— 本アプリの最重要前提

| 学年 | 年間標準時数 | 授業週数 | **週コマ数** | 週5日で1日平均 |
|---|---|---|---|---|
| 小1 | 850 | 34 | 25.0 | 5.0 |
| 小2 | 910 | 35 | 26.0 | 5.2 |
| 小3 | 980 | 35 | 28.0 | 5.6 |
| 小4〜小6 | 1015 | 35 | **29.0** | 5.8 |
| 中1〜中3 | 1015 | 35 | **29.0** | 5.8 |
| 高（全日制標準） | — | 35 | **30.0** | 6.0 |

**この数字が設計を決定づける。** 月〜金・1日6コマ＝週30枠に対し、小4以上と中学校は29コマ、高校は30コマを詰める必要がある。
**空き枠は週0〜1コマしかなく、実質的に「ほぼ完全充填問題」である。**

したがって：

- ハード制約のみで組むと、利用者が少しでも条件（教員の不在日、特別教室の制限など）を追加した瞬間に実行不可能になる
- **全制約をソフト制約（違反にペナルティ）として実装することは必須要件**であり、選択肢ではない
- 高校が週30コマ＝完全充填になるため、多くの学校が7時間目設定や65分授業等で枠を増やしている。**1日のコマ数は校種・曜日ごとに可変で持つ必要がある**

### 1.3 学級規模・学校規模

学級編制の標準（義務標準法）

- 小学校：**35人**。令和3〜7年度で段階的に引き下げ、**令和7年度に完成済み**
- 中学校：40人→**35人**。**令和8年4月1日施行**で、R8=中1、R9=中2、R10=中3 と段階実施（現在はR8＝中1のみ35人、中2・中3は経過措置で40人）
- 高等学校：40人

学校規模の区分（公立小・中学校の適正規模・適正配置等に関する手引）

| 区分 | 学級数 |
|---|---|
| 過小規模校 | 1〜5学級 |
| 小規模校 | 6〜11学級 |
| **適正規模校（標準）** | **12〜18学級** |
| 大規模校 | 19〜30学級 |

1校あたりの平均規模（令和7年度学校基本調査の在学者数・学校数から算出）

| 校種 | 学校数 | 在学者数 | 1校平均 | 概算学級数 | 1学年あたり |
|---|---|---|---|---|---|
| 小学校 | 18,607校 | 581.2万人 | 約312人 | 約9学級 | 約1.5学級 |

平均は9学級だが、大規模校は30学級まで存在するため、余裕を見て36とする。

### 1.4 校種ごとの時間割編成の実態（制約の中身）

**小学校 — 学級担任制＋専科**

- 原則として学級担任が1クラスの大半の教科を担当する。したがって「教員の重複」制約はクラス内では自明に満たされ、**難所は専科教員と特別教室に限定される**
- 文部科学省は小学校高学年で **外国語・理科・算数・体育** を優先的に専科指導の対象としており、令和4年度から教職員定数を措置して段階的に推進。中教審では3〜4年生への拡大も議論されている
- → 要件：教員は「学級担任」と「専科」の2種を区別して持つ。担任は自クラス限定、専科は複数クラス担当

**中学校 — 教科担任制**

- 全教科が教科担任制。教員の**週の持ちコマ数は平均18.1コマ**（令和4年度教員勤務実態調査。令和元年度は18.0コマ）で、**21コマ以上を担当する教員が33%**に増加している
- → 要件：**教員ごとの週持ちコマ数上限**をソフト制約として持つ（既定18、上限設定可）。これが無いと特定教員に偏った解が出る
- 部活動・給食・清掃の時間帯があるため、放課後の枠は授業に使えない

**高等学校 — 単位制・選択科目の同時展開**

- 選択科目や習熟度別指導では、**学級と受講集団（講座）が一致しない**。同一時間帯に複数講座を並列開講し、生徒が教室を移動する
- 単位制高校では「基礎科目を履修しないと発展科目を履修できないため入学年次の教育課程が過密になる」といった課題が指摘されている
- → 要件：**「クラス」ではなく「講座（受講集団）」を割当の単位とするデータモデルが必須**。小・中は「1クラス＝1講座」の縮退ケースとして扱う
- → 要件：**選択科目群の同時展開制約**（学年内の複数講座を同一コマに揃える）

**特別支援学級・通級による指導**

- 特別支援学級在籍者は約35万3千人（義務教育段階の児童生徒の3.7%）で、平成24年度比で2倍以上に増加。通級による指導は約16万5千人
- 特別支援学級の児童生徒が「交流及び共同学習」として通常学級の授業に参加するため、**特別支援学級と通常学級の時間割の整合**が必要
- → 要件：特別支援学級を学級として登録でき、特定教科について通常学級と同一コマに配置する制約（＝同時展開制約の再利用）を持つ

## 2. 確定要件

### 2.1 性能要件（実測に基づく）

`benchmarks/solver_benchmark.py` で上記の実態に即したインスタンスを構成し計測した結果：

| インスタンス | 変数 | 制約 | 求解時間 | 結果 |
|---|---|---|---|---|
| 小学校 12学級（週29コマ） | 4,464 | 1,884 | 1.06s | Optimal |
| 小学校 18学級 | 6,696 | 2,856 | 0.86s | Optimal |
| 小学校 24学級 | 8,928 | 3,768 | 1.45s | Optimal |
| 中学校 9学級（週29コマ） | 3,348 | 1,848 | 0.80s | Optimal |
| 中学校 12学級 | 4,464 | 2,274 | 2.09s | Optimal |
| 中学校 18学級 | 6,696 | 3,456 | 0.81s | Optimal |
| 高校 15学級（週30コマ・選択展開） | 4,710 | 3,240 | **5.92s** | Optimal |
| 高校 18学級 | 5,640 | 3,960 | 0.34s | Optimal |
| 高校 21学級 | 6,570 | 4,590 | 0.53s | Optimal |
| 高校 24学級 | 7,500 | 5,130 | **24.35s** | Optimal |
| 高校 27学級 | 8,430 | 5,880 | 0.74s | Optimal |
| 高校 30学級 | 9,360 | 6,450 | 2.74s | Optimal |

**結論（重要）**

1. **小学校・中学校は 1〜2秒で安定して解ける。** 同期APIで問題ない
2. **高校は 0.3秒〜25秒とばらつき、規模と相関しない。** 分枝限定法の探索運に左右されるため、**求解は非同期ジョブとし、進捗表示とタイムアウトを設ける必要がある**
   - 前提が変わったため、当初「非同期ジョブ基盤は不要」としていた判断はここで撤回する
   - ただしWebSocketは不要で、ジョブID＋ポーリング（2秒間隔）で十分
3. 求解には**必ず時間制限（既定60秒）を設定し、時間内の最良解＋未充足コマ数を返す**。CBCは時間制限時に暫定解を返せるため、「解なし」で終わらせない
4. 部分再最適化（固定率30〜95%）は 0.5〜0.9秒で完了するため、**微調整→再提案のループは対話的な速度で回せる**

### 2.2 データモデル要件

| エンティティ | 必須属性 | 備考 |
|---|---|---|
| 学校 | 校種（小/中/高）、1単位時間（45/50分）、曜日数、曜日別コマ数 | 校種でプロファイルを切替 |
| 学年 | 学年、年間標準時数、授業週数 | 週コマ数を自動算出 |
| 学級 | 学年、組、種別（通常/特別支援） | 1〜36学級 |
| 教員 | 氏名、担当教科、種別（担任/専科/教科担任/非常勤）、**週持ちコマ上限**、不在枠 | 非常勤は勤務曜日限定 |
| 教科 | 名称、校種、標準時数/標準単位数 | 上表をマスタとして同梱 |
| **講座** | 教科、担当教員、受講学級（複数可）、週コマ数、使用教室 | **割当の単位。小中は1学級＝1講座** |
| 教室 | 名称、種別（普通/理科室/音楽室/体育館/家庭科室/PC室）、収容 | 特別教室は排他 |
| 時間割 | 学校、年度、バージョン、状態 | 提案→編集の履歴 |
| 割当 | 時間割、講座、曜日、コマ、教室、**固定フラグ** | 固定＝再提案時に保持 |

| H3 | 1教室・1コマに2つの講座を置かない | 全校種 |
| H4 | 配置禁止枠（土曜午後、行事枠）には置かない | 全校種 |

| H6 | 固定（ロック）された割当は動かさない | 全校種 |

### 2.4 前回タスク一覧への差分

以下を追加または変更する。

**追加**

- [ ] **1-7** 校種プロファイル（小/中/高）の実装。1単位時間、曜日別コマ数、週コマ数の自動算出、既定の教科マスタを校種ごとに切替
- [ ] **1-8** 標準授業時数マスタの同梱（上表をシードデータとして投入し、学級を作れば必要週コマ数が自動で埋まる状態にする）
- [ ] **1-9** 「講座（受講集団）」モデルの実装。高校の選択科目・習熟度別展開、および特別支援学級の交流を同一の仕組みで表現する
- [ ] **1-10** 同時展開制約（S4/S5）の実装
- [ ] **1-11** 教員の週持ちコマ数上限（S3）と不在枠（H5）の実装
- [ ] **1-12** 2コマ連続配置（S8）の実装
- [ ] **4-7** **求解の非同期ジョブ化**（`POST /solve` → ジョブID即返し、`GET /solve/{job_id}` でポーリング）。求解時間制限（既定60秒）と暫定解の返却
- [ ] **5-5** 求解中の進捗表示（経過時間・暫定の未充足コマ数）とキャンセル
- [ ] **5-6** **講座別ビュー**の追加（クラス別・教員別に加え、高校では講座単位の確認が必要）
- [ ] **7-7** 教室（特別教室）マスタと教室割当のUI

**変更**

- 前回「非同期ジョブ基盤・進捗表示は不要（実測により）」としたスコープ判断を撤回する。小・中のみを対象とするなら不要のままだが、高校を対象に含めるため必要。ただしポーリングで足り、キュー・ワーカー基盤までは不要
- 規模要件を「1〜36学級」に確定
- フロントエンドスタックを **React + TypeScript + Vite + @dnd-kit** に確定

### 2.5 スコープ外（初版）

- 年間の時数管理（週時間割のみを扱い、年間の進捗管理・振替は対象外）
- 定時制・通信制課程、中高一貫の6年間一括編成
- 生徒個人単位の履修登録（選択科目は「講座」までを扱い、生徒の割り振りは対象外）
- 部活動・行事予定との連携
- 認証、複数ユーザー、複数校、年度をまたぐ管理
