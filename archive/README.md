# アーカイブ（2019年の実験）

このディレクトリには、2019年7月に行われた初期の実験を保存している。
現行のアプリケーションでは使用していない。

## 強化学習アプローチ（未達成）

`env/` は OpenAI Gym の環境として時間割問題を定義したもの。`keras0000.py` は
最小ケース（2学級・3教科）、`keras0001.py` と `chainer0001.py` は実問題
（6学級・16教科）を DQN で解こうとしたが、実問題は解けないまま中断している。

依存ライブラリ（旧 gym / keras-rl / Chainer・ChainerRL）はいずれも開発が終了して
おり、そのままでは実行できない。また `_is_done()` の中で `sys.exit(0)` を呼んで
いるため、解が見つかった瞬間にプロセスが終了して学習ループが完了しない不具合が
残っている。

## 線形計画法アプローチ（成功）

`timetable_linear_programming.ipynb` は PuLP による整数計画の実験で、
5学級×6日×5コマの時間割で最適解に到達している。現行の `backend/app/solver/`
はこのノートブックを出発点としている。
